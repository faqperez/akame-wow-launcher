# Akame WoW Launcher

Launcher oficial para el servidor Akame WoW - Classic+ 3.3.5a

## Características

- ✅ Interfaz gráfica profesional
- ✅ 15 parches esenciales para WoW 3.3.5a build 12340
- ✅ Parches HD opcionales (4GB RAM + fix mouse)
- ✅ Sistema de backup automático
- ✅ Patch personalizado para clases custom:
  - Undead Paladin
  - Troll Druid
  - Blood Elf Shaman

## Requisitos

- Python 3.8 o superior
- Windows 10/11
- Cliente WoW 3.3.5a build 12340

## Instalación

1. Descarga la última versión desde [Releases](https://github.com/faqperez/akame-wow-launcher/releases)
2. Extrae el archivo ZIP
3. Ejecuta `run.bat`

## Uso

1. **Seleccionar Carpeta**: Haz clic en "Seleccionar Carpeta" y elige la carpeta de tu cliente WoW
2. **Verificar Cliente**: El launcher verificará automáticamente el cliente
3. **Aplicar Parches**: Haz clic en "Aplicar Parches" para parchear el cliente
4. **Opcional - Parches HD**: Marca la casilla "Habilitar parches HD" para 4GB RAM y fix de mouse
5. **Jugar**: Haz clic en "INICIAR WORLD OF WARCRAFT"

## Clases Custom

Este launcher habilita las siguientes combinaciones de raza/clase:

| Raza | Clase |
|------|-------|
| No-muerto (Undead) | Paladín |
| Troll | Druida |
| Elfo de Sangre (Blood Elf) | Chamán |

## Desarrollo

Para ejecutar desde el código fuente:

```bash
cd launcher
python src/launcher.py
```
